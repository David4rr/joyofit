# Fixture sources

Two kinds of fixtures: third-party `.hwt` packages from public GitHub repositories (non-branded, with a stated or
permissive licence) and synthetic packages generated by this repository. Fixtures that imitate third-party brands
(Apple, Nike, Hublot, Carrera look-alikes) and files without a licence were removed; their coverage was replaced by the
synthetic ones below.

## Synthetic (`synthetic/`)

Built from scratch by `synthetic/generate.ts` with this package's own writers (`createHwt`, `FaceBuilder`, `buildMessage`
with `SCHEMA_V1`, `encodeImage`, `writeZip`). No third-party artwork; the images are flat colour bands, stripes and block
digits, the previews are 4 x 4 JPEG placeholders. Regenerate with `bun fixtures/synthetic/generate.ts`;
`test/synthetic.test.ts` fails if the committed files differ from the generator output. Packages are our own, not
exports of Huawei's tools, so they prove the codec's handling of each container/layout, not that a watch accepts them.

| File | Covers |
|---|---|
| `SynthV1Hands.hwhd02.hwt` | HWHD02, version 1 layout; image encoder with `minRun: 2` (every run of 2+ pixels is an RLE record); unused image slot 0 (table entry of size 0); v1 static image, 4 text labels (white, value 134...), 6 hands with float angles (-150..150, -135.5..135.5 ...); signature `55 55 55 55 01 00 00 01`. Replaces the `Carrera` look-alike. |
| `SynthV1Glyphs.hwhd02.hwt` | HWHD02, version 1 layout; `minRun: 4` images; signature `2e 2e 2e 2e 01 00 00 01`; 2 static images, 8 glyph tables (value types 59, 60, 61, 62, 51 with a blank slot 0, 70, 71, 52), one 0..360 hand (value 154) with pivot (13, 226); `title_en`/`title_cn` repeated after each element. Replaces `SimpleItalic`. |
| `SynthNested.hwhd09.hwt` | HWHD09 (466 x 466), version 2 layout in a **nested zip** `com.huawei.watchface` (`watchface.bin`, `watchface/res/*.png`, `watch_face_config.xml`, `watch_face_info.xml`); outer `ability.xml` and `hashCode` (SHA-256 of description.xml, com.huawei.watchface, ability.xml, watchface.bin; the real exporter's fourth input is unknown); background, hour/minute digits, seconds hand, AOD copies. Replaces the two `Hublot` GT3 files (nested zip and zip-with-`hashCode` formats). Gap: the originals had zip data descriptors, which our zip writer does not emit. |
| `SynthBand.hwhd07.hwt` | HWHD07 (368 x 194), flat version 2 layout; background and time element. Replaces `Nike9.band9` for the HWHD07 description/resolution. |
